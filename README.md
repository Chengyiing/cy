# Chengyi Cai — Academic website

Personal website for Chengyi Cai, PhD student at Carnegie Mellon University's Heinz College.

Live site: https://chengyiing.github.io/cy/

## Files

- `index.html`: biography, research projects, and contact information.
- `style.css`: shared layout and responsive styles.
- `coursework.html`: existing visualization and coursework archive.
- `assets/CV_ChengyiCai.pdf`: CV opened directly by the navigation and homepage links.
- `assets/chengyi-cai.jpg`: profile photograph.

## Updating

Edit the relevant HTML text to update biography and research. Replace `assets/CV_ChengyiCai.pdf` with a newer PDF using the same filename to keep links working. The supplied CV is preserved as uploaded; it does not yet include the PhD entry or latest grid-planning research.

This is a static HTML/CSS site; no build step is required. Preview with `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.
